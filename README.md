# heuhardware-exp
哈工程HEU《计算机硬件综合课程设计》课程资料

全套资源合集，适用19版与24版培养方案。26版培养方案目前未知，适用情形不明。

## 资源内容
1. 实验必备软件 Quartus Prime 、ModelSim（注意：不是《电路与电子》系列课程的 Multisim ） 全套软件资源和下载安装教程
2. 全部课程课件（8次课的所有课件）、参考书目电子版、部分选做实验单独讲解、引脚约束图
3. 所有实验的代码、框图（包括必做内容、选做内容），仿真波形图及其讲解（参照波形图验收时讲解会用到），选做实验包含的引脚约束，板卡文件。
4. 实验报告模板（需要将工程文件截图上传模板）

## 特别提醒
本实验课程学分为1（24版），开课时间为第2~5周，考察类型为考查课。该课程对**优秀率存在限制**，若需要达到优秀评级，需提交**所有工程源文件**，并在必做实验中完整按照仿真要求设计仿真波形，理解波形与电路含义，并在验收过程中回答老师提问。

因而，若你的工程文件大部分为AI生成，请**自行检查并去除相关AI痕迹，并规范文件命名，并充分理解各组成部分。**

选做实验重要程度较低，仅在同等必做实验分数情况下以选做实验完成程度区分位次。
